AI Waste Classification ♻️

About

AI Waste Classification is a machine learning project that classifies waste images into different categories using a trained deep learning model.

Features

- AI-based waste image classification
- Image upload for predictions
- Automatic waste category detection

Project Files

- "app.py" — Main application
- "categories.json" — Waste category information
- "requirements.txt" — Python dependencies
- "waste_classifier_under25mb.keras" — Trained classification model

Installation

1. Clone this repository:
   
   git clone https://github.com/shubhamdayal91-pixel/AI-Waste-Classifications.git

2. Open the project folder:
   
   cd AI-Waste-Classifications

3. Install the dependencies:
   
   pip install -r requirements.txt

Run the Application

Run the application using the command appropriate for your project.

For Streamlit:

streamlit run app.py

For Flask:

python app.py

Goal

To help people identify waste categories and encourage better waste segregation and recycling.
